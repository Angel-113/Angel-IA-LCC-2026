# Herramientas de inteligencia artificial que he usado en mi vida cotidiana

## 1. Gemini

Gemini es una herramienta que uso de forma concurrente. Las principales formas de uso son
investigación, generación de ejemplos de código, generación de ejemplos de párrafos, resolución
de dudas, búsqueda de posibles bugs, validación de ideas de acuerdo a material consultado,
formateo de código según un estándar dado, etc.

Es mi principal herramienta de trabajo, pero, para proyectos personales, trato de no usarla. Al
menos no para generación de código directamente. Solo para ideas, fuentes y comparación de
arquitecturas. Hoy, junto con ChatGPT, la estoy usando para diseñar un repositorio plantilla
para mis futuros proyectos en C.

## 2. Melody Seek

Una herramienta de inteligencia artificial específicamente diseñada para identificar audio
(especialmente música) de fondo. La uso principalmente cuando me gusta la música de fondo
de un reel de Instagram o un vídeo de YouTube que no señala claramente qué audio está usando.

## 3. Notebook LM

Notebook LM es una herramienta para estudio. Permite generar audios, videos, presentaciones,
reportes, cuestionarios, flashcards etc. La uso principalmente cuando tengo dudas y no quiero
leer (o más bien, no tengo tanto tiempo para sentarme a leer) o cuando necesito reforzar los
aprendizajes de una lectura. Usualmente divido las instancias de uso por libros. Es decir, un
libro por tema. Así puedo hacer cuestionarios específicos para el capítulo que esté leyendo.
Actualmente lo estoy usando mucho con *Computer Networks* de Andrew S. Tanenbaum.
